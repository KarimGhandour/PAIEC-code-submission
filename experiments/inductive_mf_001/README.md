# inductive_mf_001

Rejected strict cross-family rank-16 factor transfer. Frozen numerical functions and a runnable authorized-array transfer wrapper are released. The full historical algorithm is a provenance text snapshot. No encoder weights, embeddings, checkpoint or raw panels are bundled.

From the repository root, run `python scripts/verify_results.py` to verify released aggregate/reference arithmetic. See [data availability](../../docs/reproducibility.md) for what cannot be regenerated, and [results](../../docs/experimental_results.md) for the interpretation. Full record-level scoring, when authorized records are supplied, uses `python scripts/score_records.py --help`.
